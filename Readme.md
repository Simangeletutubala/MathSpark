# MathSpark – Interactive Mathematics Learning App

**Making mathematics fun, visual, and easy to understand.**

MathSpark is an interactive mathematics learning application designed to help South African Grade 4 learners build confidence and develop a stronger understanding of mathematical concepts.

The app uses colourful visuals, interactive activities, and simple explanations to make mathematics more accessible, especially for learners who struggle with reading or understanding traditional text-based lessons.

## About the Project

MathSpark was inspired by my experience as a Mathematics educator and my passion for software development.

The goal is to create a learner-friendly digital environment where children can explore mathematical concepts at their own pace, practise essential skills, and develop a positive attitude towards mathematics.

The application is designed with the South African Grade 4 mathematics curriculum in mind.

## Features

- **Visual learning:** Uses familiar objects such as apples, stars, and blocks to explain mathematical concepts.
- **Interactive activities:** Encourages learners to participate actively in their learning.
- **Learner-friendly design:** Colourful, engaging, and easy-to-navigate interface.
- **Accessible explanations:** Supports learners who struggle with reading through visual representations and simple instructions.
- **Mathematics practice:** Helps learners strengthen their understanding of fundamental mathematical concepts.
- **Curriculum-focused learning:** Supports mathematics learning aligned with the South African CAPS curriculum.

## Getting Started

To run the project locally, follow these steps:

### Prerequisites

Make sure you have the following installed:

- Node.js
- npm
- Git

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/Simangeletutubala/MathSpark.git
   ```

2. Navigate to the project directory:

   ```bash
   cd MathSpark
   ```

3. Install the dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL displayed in your terminal to view the application.
